# Linked Field

Linked Field allows you to link fields in the field formatter settings. E.g. you have a content type teaser with an
image and a link field and you want to link the image to the entered link.

For a full description of the module, visit the
[project page](https://www.drupal.org/project/linked_field).

Submit bug reports and feature suggestions, or track changes in the
[issue queue](https://www.drupal.org/project/issues/linked_field).

## Requirements

- [Field formatter settings](https://www.drupal.org/project/field_formatter_settings)

Optional dependencies

- [Token](https://www.drupal.org/project/token)  - Gives you access to the token browser
- [YAML](https://www.drupal.org/project/yaml_editor) Editor - Loads an Ace editor which makes YAML editing more fun

## Installation

Install as you would normally install a contributed Drupal module. For further information,
see [Installing Drupal Modules](https://www.drupal.org/docs/extending-drupal/installing-drupal-modules).

## Configuration

1. Go to "Manage display" and click the settings button.
2. Then you can just tick the "Link this field" checkbox
   and you will see a destination field and the token list.
3. Select a token and click "Update".
4. When you are missing some attributes edit them on the configuration page.
